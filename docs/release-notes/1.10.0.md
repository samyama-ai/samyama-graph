# Release Notes — v1.10.0

**Date:** 2026-09-29 · **Commits since v1.9.0:** 58

Where 1.9.0 was interoperability, 1.10.0 is **the security and tenancy surface**:
the HTTP API can require a credential, users have passwords, the listener can
serve TLS, snapshots can be encrypted at rest, and every state-changing request
can be recorded. Alongside that, the feature 1.9.0 shipped broken now works.

## Read this before upgrading

- **Full-text search works on a server for the first time** (#1468). The 1.9.0
  notes said plainly that it did not: the index was maintained only on a store
  with no event subscriber. If you tried `CALL db.index.fulltext.queryNodes`
  against a running server and got nothing, that is why, and it is fixed.
- **The HTTP API can require a credential** (REL-08, #1328, #1423), with
  **users and passwords beside machine tokens** (#1430) and **auth, roles and
  tenant isolation** (#1521). Authentication is off by default, so an existing
  deployment does not change until you turn it on — but #1328, open since the
  browser path was closed in 1.9.0, is now closed properly.
- **Tenant quotas are enforced at admission, not at persist** (#1483, #1492),
  and **a bulk import that would cross the quota is refused before writing any
  of it** (#1495). A request that used to be accepted and then fail part-way
  now fails immediately, which changes the error your client sees.
- **`PATCH /api/tenants` changes only what it mentions** (#1494). If you relied
  on the old behaviour of unmentioned fields being reset, that was a bug.
- **Answers change where they were wrong**: an edge-type scan is ascending, so
  the same graph gives the same order (#1509); `CALL … YIELD … WITH` is planned
  in the order it is written (#1375); `hierarchy_lca` is evaluated once, not
  once per row (#1399); a mutating procedure called through `CALL` is routed to
  the write executor (#1468); `/optimize/solve` honours its seed (#1478).
- **`hnsw_rs` 0.2.1 → 0.3.4** (#1422) clears RUSTSEC-2026-0300. Vector recall
  was measured either side of the upgrade rather than assumed.

## Added — security, tenancy and operations

- **TLS on the HTTP listener** (REL-09, #1427) and **snapshots encrypted at
  rest** (REL-09, #1429).
- **Every state-changing request can be recorded** (REL-08, #1428).
- **The default tenant's quotas can be raised from the command line** (#1483).
- **Published snapshots are scanned for personal identifiers** (TRUST-10, #1438).
- **Model-generated graph state is tagged, excludable and reversible**
  (TRUST-05, #1414).

## Added — language, ML and clients

- **Query parameters over HTTP and RESP** (#1463) — the binding form clients
  needed instead of interpolating values into the query text.
- **Graph embeddings: FastRP and node2vec, callable from Cypher** (ML-06, #1445).
- **`ANALYZE` recomputes the planner statistics and reports them** (LANG-13, #1446).
- **fp16 vector quantization**, with the memory saving and the recall cost both
  measured (NDS-09, #1385).
- **The Python SDK releases the GIL and gains an async surface** (#1436, API-12),
  and a **`%%cypher` magic that returns a DataFrame** (INT-09, #1441).
- **A documented pattern and reference sketch for microcontroller clients**
  (API-15, #1458).

## Fixed

- A query that nests deeper than the stack can parse is refused rather than
  aborting the process (#1475).
- `/api/vector-search` refuses a graph it cannot serve (#1476) and asks the
  index which property holds the vectors (#1481).
- The background indexer starts with or without persistence (#1469).
- Join operators drain their right side through `next_mut` too (#1479), with a
  ratchet so an operator holding children cannot inherit the read-only form
  (#1488).
- `nodeSimilarity` was callable and not-callable depending on the list consulted
  (#1389).
- One implementation of expansion in `ExpandOperator`, not two (#1457).

## Measurements corrected in this cycle

- **PERF-06** reports throughput beside cores, so it cannot be met by wasting
  them (#1461), and a deep traversal is measured for whether it uses its cores
  (#1455).
- **LANG-09** read 0 of 3 because the probe never configured an import root
  (#1444) — a measurement fault, not an engine one.
- **OPT-02** gains significance tests for the solver comparison (#1435).
- **ALGO-06** probes the three write-back modes (#1431).
- The dead `REQ-*` requirement scheme is retired (#1453), and the docs index is
  now a check rather than a convention (#1450) — which is what required these
  notes to exist before the tag.
