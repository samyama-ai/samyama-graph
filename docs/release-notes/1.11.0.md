# Release Notes — v1.11.0

**Date:** 2026-10-05 · **Commits since v1.10.0:** 84

Where 1.10.0 was the security and tenancy surface, 1.11.0 is **the way data gets
in, and a correctness sweep that followed from finally testing it**. Parquet is a
reading clause, CSV and JSON import stream in batches and know what graph they
belong to, and natural-language querying reaches every client. Behind that,
raising workspace line coverage from 86.9% to 96.2% found **43 bugs**, all fixed
here.

## Read this before upgrading

- **Input that used to be accepted is now refused.** Each of these was a way to
  write something wrong and find out later:
  - a **text query against a vector index built with a different embedding
    model** (#275, #1544) — the index now records its model and rejects a
    cross-model search rather than returning meaningless neighbours;
  - a **CSV or JSON import naming a foreign graph** (#336, #1545);
  - a **node whose new label would collide with an existing unique key**
    (#1590, #1598) — and a node is now indexed under a label it gains *after*
    creation, which it was not before;
  - a **snapshot whose query catalog does not match its header** (#1154,
    #1587).
- **A refused write now fails the statement** (#1603, #1604, #1605, #1637)
  instead of being skipped while the statement reported success. If you relied
  on partial application, the error surfaces where it always should have.
- **`max_connections` is enforced over both RESP and HTTP** (#1594, #1602), and
  **write statements have a deadline honouring the tenant's
  `max_query_time_ms`**, with a failed statement undone (#1593, #1601). A
  long-running write that previously ran to completion can now be cut off.
- **`query_readonly` is enforced by the server**, not only by the client
  (#1628, #1632, #1640). A client that sent a write through it was previously
  trusted.
- **The logical WAL's XOR "checksum" is now CRC-32** over sequence plus entry
  (#1547). **Existing WALs replay unchanged**, including files that mix both
  formats: a new record carries a format marker in the top bit of its length
  word, and a record without that marker is read as legacy and still verified
  with the XOR. A test asserts it. The old checksum was 8 bits of signal, blind
  to the sequence number and to the same bit flipped in two bytes, while the
  docs called it CRC32 — so this closes a gap between what was documented and
  what was computed. Only a third-party tool that parses *new* records needs to
  learn the new layout.
- **Algorithm procedure names are no longer in `KNOWN_FUNCTIONS`** (#1456,
  #1546). Calling one as a function rather than through `CALL` now fails.
- **A second `WHERE` in a leading reading run is ANDed, not overwritten**
  (#1823, #1825). A query written with two `WHERE` clauses previously had the
  first silently discarded, so it returned too many rows. It now returns the
  right ones, which is a change in answer.
- **`WITH *` sees what a `MATCH` after an earlier `WITH` bound** (#1591,
  #1599), and **`RETURN *` expands inside `CALL { }`** (#1606, #1638). Both
  previously returned fewer columns than written.

## Added — import and the ingest path

- **`LOAD PARQUET`**, a Parquet reading clause behind the existing `LOAD CSV`
  import gate (#1098, #1586).
- **CSV imports stream in batches**, and the import routes carry a real body
  limit (#336, #1580).
- **An edge import mode for CSV and JSON** (#336, #1545).
- **A node can be looked up by its external key** under a unique constraint
  (#542, #1585).
- **`apply_mutations` probes, checks quota and locks the WAL once per batch**
  rather than per row (#1109, #1588).
- **One finish for a sequence of bulk loads**, not one per import (#1807,
  #1816).

## Added — natural language and clients

- **`GRAPH.NLQ`, and NLQ in the Python and TypeScript SDKs**, each reading its
  own provider's API key (#438, #1581).
- **NLQ in the Rust SDK and the CLI** (#438, #1539).
- **Every SDK streams rows** (#1628, #1632, #1640).
- **`/api/query` streams results with backpressure under one bounded read**
  (#1393, #1554).
- **A TypeScript SDK option passed as `undefined` keeps its default** (#1595,
  #1597), and **`connectHttp` takes a timeout** (#1326, #1533).

## Added — planner and observability

- **`PROFILE` prints an estimate beside each operator's row count**, and a
  filter on a node scan is fused into it (#1615, #1624, #1641).
- **`EXPLAIN` describes eleven operators that printed `Unknown`** and stopped
  the tree there (#1826, #1827).
- **A statement can be read under GQL defaults on request** (#1642, #1644,
  #1647), re-validated after the dialect rewrite so the rewrite cannot smuggle
  a query past the check (#1649).
- **The GPML conformance suite runs in CI** against a reviewable baseline
  (#1645, #1650).
- **Cross-hierarchy conjunctions are driven from the most selective axis**
  (#350, #1345, #1584); **an expand is pruned on comparisons with an
  already-bound variable** (#1069, #1583); **`shortestPath` over endpoints an
  earlier `MATCH` bound searches from those rows** (#1633, #1639).

## Added — snapshots and catalogs

- **A `.sgsnap` carries the index catalog**, so an import declares exactly the
  source's indexes (#1506, #1542).
- **A read-only snapshot's catalog answers are materialised in a sidecar**
  (#1158, #1612).
- **Verified question catalogs for three KGs**, one runnable from the CLI
  (#1154, #1611). Catalogs are private unless built for release, and an
  observed one needs a written sign-off (#1159, #1589).
- **A failed snapshot write keeps the last good snapshot** (#1520, #1525).

## Fixed

- **43 bugs found by new coverage tests**: 21 alongside the sweep that took
  workspace line coverage from **86.9% to 96.2%** (#1555), then 11 more — RESP
  framing, panics, an exit segfault, list slicing and equality, planner scoping
  (#1578) — and 11 after that: planner fast path, `MERGE`/`SET` maps, temporal
  offsets, GraphML, vector, OEH, `CypherProblem` (#1579).
- **A timed-out HTTP transaction is reported as timed out, not unknown**
  (#1518, #1526).
- **A broken snapshot upload answers with its multipart error, not "no file"**
  (#1596, #1600).
- **A vector in the index is always its own nearest neighbour** (#1498, #1534).
- **Every walk across edge types is reproducible**, not only a scan of one
  (#1509, #1550); **`WHERE p … ORDER BY p` reads `p` once per row, not twice**
  (#593, #1548); **a NaN fitness ranks worst in every solver** (#1634, #1638).
- **Counting an edge type counts every edge of it**, not every indexed one
  (#1806); **top-N-by-degree reads the catalog's degree maps** (#304, #1809)
  and **selects the top K inside the degree aggregate** rather than with a
  `Sort` above it (#1811).
- **A string comparison reads its operands in place, not as copies** (#750,
  #1553); **an integer sort key no longer reaches `i64::cmp` through six rank
  computations** (#1819, #1829); **a neighbour label is a bit, not a hash per
  edge** (#1812, #1814).
- **The catalog and the edge-type index are rebuilt on every core** (#1824,
  #1828).
- **The Dockerfile's Rust was three versions behind the lockfile**, and nothing
  compared them (#1523). The image failed to build for 1.10.0 for this reason;
  a check now compares the pin against the lockfile's MSRV on every PR.
- **Eleven examples panicked when run without `--data-dir`**; they now say so
  and exit 2 (#1635). Several benchmarks that panicked on every run were fixed
  to read properties through `node_property` (#1631, #1636).

## Measurements and claims corrected in this cycle

- **A timing example measured an allocator nobody ships**, and the probe that
  blamed the allocator ran a different one (#750, #1817, #1818, #1820).
- **REL-04 recorded**: 1,000 kill points, 0 acknowledged writes lost (#1535).
- **The ACID claims are pinned to tests**, and what had drifted was corrected
  (#1309, #1531).
- **OPT-14's real gap stated**: there is no linear model to export (#1549).
- **`ldbc_benchmark` discloses its warm-up count and cold-first-run bias**
  (#752, #1536); **`traversal_parallelism` says which expansion operator
  PERF-06 exercises** (#1538); optimization benchmark paths are qualified
  (#1452, #1537).
- **README result lines are pinned to their artifacts** (#1330, #1552) and
  XK02 and the Cross-KG table are quoted from `verified-results.csv` (#1527).
- **The multi-hop ADR was renumbered 035 → 040**, so no two ADRs share a
  number (#1515, #1529).

## Packaging

- **The `samyama` ↔ `samyama-sdk` publish cycle is broken**, and all six crates
  publish (#1541).
- **The GPU dispatch node threshold is backend-aware** (#1402, #1540).
