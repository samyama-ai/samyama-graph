# Release Notes — v1.14.0

**Date:** 2026-11-03 · **Commits since v1.13.0:** 152 (82 non-merge)

This release makes long-running work interruptible. Graph algorithms and
optimization solves now stop at a deadline or a budget instead of running to
completion, and a forwarded shard command that goes unanswered fails instead of
hanging. It also adds a derivative-free global optimizer, per-call NLQ cost
accounting, label-qualified snapshot dedup keys with per-key merge reporting, and
a catalog of the public knowledge graphs.

## Read this before upgrading

- **The CLI moved to `crates/samyama-cli`.** This is a repository path change
  only. The crate name `samyama-cli` and the binary name `samyama-cli` are both
  unchanged. Builds that referenced the old `cli/` path need updating; nothing
  that installs or runs the binary does.

  **Amended 2026-11-07.** This bullet originally said "the published artifacts
  are unaffected". That was wrong. The `Dockerfile` still carried
  `COPY cli ./cli`, so the container build failed on the release tag and
  **v1.14.0 shipped without a container image until it was rebuilt**. The
  Dockerfile fix is `31d53c21` (#2056). No published image was ever broken --
  the build failed rather than producing a bad one -- but the image was late,
  and the claim that artifacts were unaffected was not true when written. See
  also *Known issues* below.
- **Algorithms now observe the query deadline.** A graph algorithm that
  previously ran to completion past a deadline will now stop and report that it
  stopped. Callers that relied on receiving a complete result regardless of
  elapsed time should raise the deadline rather than expect the old behaviour.
- **A snapshot dedup key can be label-qualified**, and a key that merges nothing
  is now reported rather than passing silently. Import output gains per-key merge
  counts, so a key that was quietly doing no work becomes visible.

## Added

- **OPT-13: L-SHADE**, a derivative-free global optimizer reachable through
  `algo.or.solve`.
- **OPT-11: a time or evaluation budget for a solve.** L-SHADE stops at its
  budget as well.
- **ALGO-12: a graph algorithm stops at the query deadline** instead of running
  to the end.
- **COST-07: an NLQ call reports the tokens and the time it cost.** The LLM-time
  counter is compared in whole microseconds.
- **KG-13: a catalog of every public knowledge graph**, including `banking-kg`
  and `market-structure-kg`.
- **Structural conventions in `.sgsnap`**, 3D Morton SGI roll-ups, and HTTP
  OEH/structure visual cues, with the four structure/hierarchy endpoints
  documented.
- **Label-qualified entity dedup keys** for snapshot import, with key aliases,
  per-key merge accounting, and a count of the values a merge drops.
- **A read-only snapshot dedup key audit**, available as a CLI command.
- **A published GQL gap analysis.**

## Fixed and hardened

- **Sharding: a forwarded command to a peer that does not answer is an error,
  not a hang.** A forwarded reply is read until the RESP frame ends rather than
  until the first read returns.
- **OPT-10: an infeasible point is never returned as feasible.**
- **OPT-07: `or.solve` writes its solution back whole or not at all**, now
  covered by a test.
- **Deleted and replaced vectors are dropped from the index**, so a deleted node
  no longer surfaces from a vector search.
- **Merge-created edges are deduplicated under an explicit policy**, and each
  merged source adjacency is indexed once during import rather than repeatedly.

## Known issues

- **The container image was late.** The CLI path move (above) broke the
  `Dockerfile`, so `publish-docker` failed on the `v1.14.0` tag and the image
  was published only after `#2056`. Nothing in CI builds the image on a pull
  request or in the nightly sweep, so the first build of a release is the
  release itself. Tracked as a CI gap; the Dockerfile's `COPY` sources are now
  the obvious thing to check, since the break came from a directory moving, not
  from the Dockerfile being edited.
- **crates.io was incomplete at release.** Only 3 of the 7 crates published on
  the tag. `samyama`, `samyama-convert`, `samyama-sdk` and `samyama-cli` did not
  exist on crates.io, and Trusted Publishing cannot create a crate -- it can
  only add a version to one that exists -- so the publish loop stopped at the
  first of them with `403 Trusted Publishing tokens do not support creating new
  crates`. All four were published by hand on 2026-11-03, so **all seven crates
  are now at 1.14.0** and later releases publish every one through CI. A second
  defect found while verifying this is fixed by `#2109`: the loop's
  skip-if-already-published branch could never run, because the step's shell has
  `-e` set and the failing `cargo publish` aborted it before the exit code was
  inspected.
