# Release Notes — v1.9.0

**Date:** 2026-09-21 · **Commits since v1.8.0:** 116

Where 1.8.0 was Cypher correctness, 1.9.0 is **interoperability and honesty about
what the engine does**: getting data in and out of other systems, saying what an
export loses, and making durability a choice with a stated price.

## Read this before upgrading

- **A write that does not reach disk is no longer reported as success** (#1274).
  If you relied on the old acknowledgement timing, writes will appear slower;
  they were not durable before. **Durability is now a choice, and the choice
  comes with its measured price** (#1309) — see `docs/ACID_GUARANTEES.md`.
- **The browser path into the unauthenticated write API is closed** (#1328). A
  page can no longer reach the write surface cross-origin. The HTTP API still has
  no authentication; that is tracked separately in #1328 and stated in
  `docs/DATA-HANDLING.md`.
- **Answers change where they were wrong**: turning the hierarchy index on no
  longer changes the answer (#1343); `percentileCont` inside a `WITH` returned
  the median whatever was asked for; a label scan yields ascending node id,
  limited or not (#1364); parallel edges are not a bridge and a reciprocal pair
  is one edge (#1308); a snapshot round trip invented a label and hid the others
  (HW-07, KG-11).

## Added — getting data out, and in

- **Full-text search**: tokenised, stemmed, BM25-scored (NDS-06, NDS-07).
- **Approximate aggregates**: HyperLogLog distinct counts, t-digest quantiles
  (NDS-10).
- **Spatial**: points, distance and bounding boxes (NDS-04).
- **GraphML export**, with the losses the format forces named (INT-05).
- **CSV export and a BI recipe** that names what CSV cannot say (INT-08).
- **Import a Neo4j graph** from `apoc.export.json` (INT-02), and **resolve GDS
  procedure names** — only where the answer matches (INT-04).
- **RDF mapping**: a round trip that moves data, with its losses named (#1362).
- **An export says what it did not carry** (INT-06). The previous loss report was
  a hardcoded `False`; it now runs.
- **A compatibility report you can point at your own queries** (INT-11).
- **How to leave**, with the steps that run and the one that does not (INT-07) —
  `docs/LEAVING-SAMYAMA.md`.
- **`CREATE VECTOR INDEX`** in the plain `ON :Label(prop)` form (NDS-11).

## Added — operations and observability

- **Query latency metrics and a dashboard over metrics that exist** (REL-10).
- **Where the memory goes, and which query was slow** (COST-06, REL-10).
- **Errors point at the place in the query that caused them** (LANG-12).
- **Row-level provenance**: a row knows where it came from, and an export can act
  on it (TRUST-03, ML-09, EVAL-10).
- **Connection management in all three SDKs** (#1326, API-06) and **type
  information for the Python SDK, with a check that it stays true** (API-12).
- **Release binaries are attached** to the release, and the arm64 image is built
  (#1327); the published image is mirrored to ECR Public by CI rather than by
  hand.

## Fixed

- **`RETURN toUpper()` aborted the server; 69 calls did** (#1365).
- A backticked variable, label or relationship type parses and binds (#1373).
- A namespaced function name may have more than one segment.
- `YIELD col AS alias` binds the alias (#1318).
- `or.solve` refuses a name it cannot run (#1341); algorithms refuse a config key
  they do not read (#1316).
- `dijkstra`, `aStar` and Yen's refuse a negative-weight graph (#1303).
- **A torn WAL tail stops replay instead of failing it** (#1311).
- A `RESP` error stays on one line (#1322).
- Drop the `Filter` an `IndexScan` has already answered (#1380).
- A temporal-times constructor the caller cannot misorder (#1304).

## Measurements corrected in this cycle

Recorded here because a published number that turns out wrong is part of a
release, not separate from it.

- **The hierarchy index makes its own corpus 2.2x slower**, and the published
  number could not see it. The HIER corpus answers two questions; the earlier
  figure was the mixture.
- **"Parallel everything" is not what we measured.**
- The durability cost is a property of the disk, so it is now measured on two
  hosts; `fsync_cost --from-env` keeps its samples and says when two of them do
  not compare.
- `NDS-09`'s probe blamed the wrong half.
- The substrate study's criticality tool ranked over every edge type.
