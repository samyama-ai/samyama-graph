# Release Notes — v1.8.0

**Date:** 2026-09-15 · **Commits since v1.7.0:** 608

The bulk of this release is Cypher correctness. **Read the first section before
upgrading:** a number of queries that returned an answer in 1.7.x return a
*different* answer here, because the 1.7.x answer was wrong. A wrong answer that
looks plausible is the failure mode these fixes address, so an upgrade can
change a dashboard without changing a query.

## Answers that change

Each of these returned something in 1.7.x. None of them returned the right thing.

- **`EXISTS` subqueries** — the patterns of an `EXISTS` subquery must all match
  *together*, not independently (#1244).
- **Relationship isomorphism** now holds across the comma-separated patterns of a
  single `MATCH`, not only within one pattern (#1233).
- **`OPTIONAL MATCH ... WHERE`** — the `WHERE` belongs to the `OPTIONAL MATCH`
  whatever variable it names (#1231), and a `WHERE` on an `UNWIND` variable keeps
  the unwound rows (#1229).
- **Variable-length paths** — a pattern returning to its own start ends there
  (#1237); a lower bound of 0 no longer collapses the path multiset (#1140);
  inline targets are pinned (#1199) and never pinned when paths are counted
  (#1202).
- **`ORDER BY`** — a failing sort key is an error rather than a silent null
  (#987), and a sort no longer looks for a string in a non-string key column.
- **`MERGE` / `SET`** — a `SET` after `MERGE` runs after it (#1215); `MERGE` finds
  an existing node through the property index.
- **`CREATE`** — a later element of a `CREATE` sees the nodes an earlier one
  created.
- **`FOREACH`** — every updating clause in the body runs (#465), and a
  `$parameter` inside the body is bound.
- **Restored and imported graphs** — `RETURN n` gave back empty nodes on an
  imported graph (#1125); five wrong answers came from reading node properties
  in the wrong place (#1185, #1187); a restore-then-change-one-property-then-
  restart cycle no longer lost the rest (#1129); a round trip now carries node
  timestamps (#1124).
- **Integer arithmetic** that leaves the 64-bit range is an error, not a wrapped
  value.
- **Temporal** — `duration.between` counts days on local time in a named zone
  (#825); a named-zone date-time plus a duration re-resolves its offset (#824).
- **`x IN null`** is null, and a `WITH` aggregate over no rows is one row.

## Added

- **Map projection** — `v {.name, key: expr, other, .*}` (#1239).
- **GQL path restrictors and selectors** (#1141), and a path mode accepted before
  the path variable, which is the order the standard uses. The engine now tells
  you when an implicit path mode changed the answer (#1149).
- **`CALL db.checkIntegrity()`** — asserts every edge references two existing
  nodes (#1143).
- **Result cache**, keyed on `(query, params, epoch)` and opt-in at the call site
  (#1153). Bounded **in bytes**: an entry count is not a memory bound.
- **`samyama verify`** — a snapshot that cannot reproduce its own answers has
  failed.
- **`CALL algo.pca`** from Cypher, with the SDK's `pca` reading columns (#1022).
- **A query result names the plan that produced it** (TRUST-06, #1034).
- **Parity exports**: `articleRank`, the four temporal primitives, and `or.solve`
  on a fixture whose optimum is known (ALGO-02).
- **Per-query row budget** (PERF-05).

## Performance and footprint

- **Relationship properties are stored in columns**; reading one no longer clones
  the edge (#1059, #1191).
- **A typed `DateTime` column** — about 9 bytes a date instead of about 134
  (#1195).
- **Batch lookups probe the index once**, not once per row (#1219).
- **Restore is linear in nodes and edges, not in bytes** (#1174).
- `ORDER BY` sorts row indices rather than `(key, record)` pairs.

## Fixed in the toolchain around the engine

- `tck_runner` passes parameters and loads fixture graphs: **81 previously
  skipped scenarios became judgeable**.
- `LINT-RATCHET` reported 0 warnings on a tree that had 943 (#1134), and now
  shows what it is counting.
- Every CI gate reports, instead of the first red hiding the rest (#1134).
- The release gate requires the `CH-REGRESS` pass to be about **the build being
  tagged**.
- The restart check compares against the store it persisted (#1178).
- Deleted-after-compaction relationships are neither counted nor exported
  (#1096).
- The NLQ write guard accepted any write that began with `MATCH`.
- Deleted the plan cache that was never wired, and the document that said it was.
